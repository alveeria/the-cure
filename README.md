# The Cure.exe

Visualisasi lirik bergaya terminal dengan animasi mengetik, efek glitch, dan gerakan kamera yang tersinkron dengan musik. Dibuat menggunakan HTML, CSS, dan JavaScript tanpa framework.

## Cara menjalankan

Buka `the-cure.html` di browser. Animasi akan berjalan otomatis; jika musik belum terdengar, klik halaman atau tekan tombol keyboard untuk mengaktifkan audio.

## Berkas

- `the-cure.html` — halaman utama dan logika animasi.
- `style.css` — tampilan terminal dan efek visual.
- `lagu.mp3` — audio pengiring.
